Aisha M.: Quick UX check — compact run rows in the playground feel dense and the affordances are unclear. Can we do a short design pass before I hand off to QA? :mag:

Tom B.: Sure. What specifically is confusing?

Aisha M.: Two things: the action on the left icon sometimes opens a replay and sometimes expands metadata. Users don't know which. Also the one-line summary reads like code (e.g., `translateText(...)`) which worries product folks.

Lina P.: For the toggle, prefer distinct verbs: "Open replay" when it launches the live player, and "Open details" when it expands metadata. Keep the icon the same but update the aria-labels.

Tom B.: Good call. Small implementation note: update aria-label instead of inner text for compact icons to avoid layout shift.

Lina P.: Accessibility: toggles must be real buttons and expose aria-expanded. Example to reuse:
```html
<button class="run-toggle" aria-expanded="false" aria-label="Open details for run 5">Open</button>
```
Toggle to true when expanded and update aria-label to "Close details for run 5". Also respect prefers-reduced-motion on the animation.

Aisha M.: About the one-line: UX prefers a human-friendly pill. Proposal: `Translate • en → fr • 3 params`. If space is tight show `Translate • en→fr • 3` and put the full string into an aria-label.

Tom B.: Love that. Use an ellipsis for visible truncation plus aria-label for full text. Also add a small action `• Schema delta: +2` when the function signature changed recently. Keep it low-contrast border + icon so color isn't the only signal.

Lina P.: For the schema delta, add aria-live="polite" on the container so screen readers notice it when the run is loaded. Use a neutral background with a subtle orange icon for visual emphasis.

Aisha M.: Error copy: instead of dumping the stack, show a calm summary line and collapse the raw trace behind "Inspect error". Example microcopy: "Tool error — retry or inspect details". Include invocation id for support.

Tom B.: Agree. Also add a small retry button next to the summary: `Retry · id: abc123`. Make the retry action keyboard accessible.

Lina P.: Keyboard nav: propose `n`/`p` to move to next/previous run (not global when inputs are focused). When focus moves announce the run title with aria-live and give the focused card a 2px solid focus ring.

Aisha M.: Tooltip idea for function defs — on hover/focus show top 3 schema fields and a link "View full schema" which opens the inspector. The tooltip must be focusable and opened with Enter/Space.

Tom B.: Tooltip perf: render summary server-side or cache the preview to avoid heavy client-side parsing. Also cap preview size and show "+ more" when large.
