eva: I made a quick test harness and reproduced with node client by forcing small write buffer sizes, confirmed a split inside the JSON token. Also saw errors like `SyntaxError: Unexpected end of JSON input` and then the client retry logic does a full reconnect which duplicates response content.

sam: Two orthogonal fixes we can do: server-side — ensure each SSE `data:` line is flushed atomically with \n\n and avoid splitting JSON across writes; or client-side — parse incrementally (streaming JSON parser) and accept partial tokens without throwing, plus detect keepalive gaps. I lean to make client resilient and still harden server.

maria: Agreed. Quick wins I'd propose:
- client: buffer and only JSON.parse complete objects; use a small streaming parser fallback; treat incomplete JSON as temporary and wait for next chunk with a short backoff (200ms) before giving up
- client: add strict duplicate suppression for reconnects (idempotency keys)
- server: emit keepalive comments `: keepalive\n\n` every 10s so clients don't assume dead
- nginx: set `proxy_buffering off; chunked_transfer_encoding on;` for our SSE endpoints

josh: I tested `proxy_buffering off` + `proxy_request_buffering off` on a staging box and the split problem reduced dramatically. Also set `sendfile off` for the proxy in our config to avoid unexpected chunk coalescing. Results: 0 failures after 30m of stress (was ~5-10/min).

maria: I'll open the PR for docs and examples showing the recommended client pattern. Short snippet to show robust client approach:

```js
let buf = '';
fetch(url, { /* ... */ }).then(r => {
  const reader = r.body.getReader();
  function pump() {
    return reader.read().then(({done, value}) => {
      if (done) return;
      buf += decoder.decode(value, {stream: true});
      // split on SSE \n\n boundaries
      let parts = buf.split('\n\n');
      buf = parts.pop(); // last piece may be partial
      for (const p of parts) {
        // p starts with "data:" possibly multiple lines
        const lines = p.split('\n').filter(Boolean);
        for (const l of lines) {
          if (l.startsWith('data:')) {
            try { const payload = JSON.parse(l.replace(/^data:\s*/, '')); handle(payload); }
            catch (e) { /* buffer will absorb next chunk, don't throw */ }
          }
        }
      }
      return pump();
    });
  }
  pump();
});
```
