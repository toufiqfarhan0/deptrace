emma_finance: Quick update — starting April 1 we're changing the approval path for recurring SaaS subscriptions. Subscriptions that are annual and under $5,000/year will move to the new self-serve auto-approval flow via the procurement portal. This should cut turnaround from days to minutes. Please read the guide: https://redwood.app/finance/saas-policy :tada:
andy_ops: Nice — does this cover upgrades within an existing subscription or only new purchases?
jordan_pm: Also curious about multi-year deals and true-ups mid-year.
emma_finance: Good Qs. Short answers: upgrades that change the annual spend above $5k will require manual approval. If an upgrade keeps you under $5k/year, it stays in self-serve. Multi-year contracts that average >$5k/year require PO & manual review. True-ups that push you over the threshold will trigger procurement review.
procure-bot: FYI — New workflow added: `Procure > SaaS > Recurring < $5K` with automated vendor verification and virtual card issuance. Logs will appear in the vendor dashboard.
dev_lead: For teams using seat-based billing that ramps quickly (e.g., infra tools), can we set a temporary hold so we don't accidentally exceed limits mid-quarter?
emma_finance: Yes — request a spend cap via the portal (Procure > Controls > Spend Caps). Ops can set a cap per vendor or per project. If you expect quick scaling, please file a pre-approval with estimated peak spend.
andy_ops: Is there any change to the virtual card limits or who can request them? We had a case last month where a card got requested by mistake.
emma_finance: Virtual card policy unchanged for now — card requests still require manager sign-off. However the auto-approval flow will issue single-use virtual cards for eligible subs, so fewer manual card requests overall. We're also adding a new audit mailing list: finance-vcards@redwood.com
jordan_pm: Does the auto-approval store the vendor contract and attach to the PO? Need that for compliance.
emma_finance: Yes — the workflow will capture vendor T&Cs and store a PDF snapshot in the PO record. If a vendor requires signature, the flow will pause and route to legal.
procure-bot: Reminder: teams should tag purchases with `#project` and `#cost-center` in the portal. Missing tags will cause the flow to fall back to manual review.
dev_lead: Nice. One more — what about renewals that are set to auto-renew on vendor side? Will procurement attempt to track and renew?
emma_finance: We will attempt to detect auto-renewals for vendors already onboarded in the portal. Procurement will send a 30-day notice to owners for any auto-renewing subs. If you want to opt out of auto-renew, set the vendor to "manual renew" in the portal.
andy_ops: Thanks, emma. Can you post the short checklist teams should follow before submitting? That'd cut questions.
emma_finance: Posted — quick checklist in the guide (link above). TL;DR: estimate annualized cost, add project & cost-center tags, confirm whether contract signature is needed, and set expected seat growth. If in doubt, select "pre-approval".
