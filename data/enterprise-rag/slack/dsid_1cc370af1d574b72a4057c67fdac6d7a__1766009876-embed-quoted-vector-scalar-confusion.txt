sam_support: yep that's it — the client sent a single string (one item) because the numpy list was turned into a JSON string. jordan_eng: quick checklist to repro/fix: 1) check the raw request body (client-side). 2) ensure you're not calling json.dumps on the inner vectors. 3) Content-Type must be application/json (not form/multipart). 4) if using ndjson/gzip, make sure each line is a JSON array/object, not a quoted string.
