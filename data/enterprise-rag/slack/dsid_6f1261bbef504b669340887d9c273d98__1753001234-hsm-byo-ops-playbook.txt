kumar: Operational point: we need a local cache for decrypted data keys per-worker. Example flow:
```
1) client uploads data -> server asks KMS to GenerateDataKey(algorithm=AES-256) -> returns {plaintext_DK, wrapped_DK}
2) plaintext_DK kept in memory on worker, used to encrypt inference payloads/embeddings, cached with TTL ~5m
3) when TTL expires, request new data key from KMS
```
This avoids HSM hits on each token.
