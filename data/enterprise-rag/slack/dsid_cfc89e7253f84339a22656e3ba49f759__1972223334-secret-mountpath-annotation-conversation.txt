olivia: Ah — v2 changed the annotation contract. The new controller reads `externalsecret.redwood.io/mount` but our CSI driver mapping layer still looks for `external-secrets.io/secret-key` to build the mount subpath. So nothing is actively creating the expected file name.

grace: Quick terraform snippet that will keep both annotations (backcompat):```hcl
resource "kubernetes_manifest" "es_compat" {
  manifest = {
    apiVersion = "external-secrets.io/v1alpha1"
    kind = "ExternalSecret"
    metadata = {
      name = var.name
      annotations = {
        "externalsecret.redwood.io/path" = var.vault_path
        "externalsecret.redwood.io/mount" = var.mount
        "external-secrets.io/secret-path" = var.vault_path
        "external-secrets.io/secret-key" = var.mount_key
      }
    }
    ...
  }
}
```
This keeps the old mapping until we roll the CSI driver.
