maya: Quick sync — Acme asked for deterministic results when we fan-out to multiple tools (search + payments API + enrichment). They want identical outputs across retries and replicas. Can we meet that for Hosted?

simon: Short answer: not for general Hosted traffic without heavy coordination. Determinism across parallel external calls is hard (external APIs, network nondeterminism). We can offer stronger guarantees on Dedicated/Private.

alex: Agree. Options: 1) Best-effort parallel with idempotency + causal ordering hints. 2) Strict sequencing (single-threaded execution per logical request) — expensive and higher tail latency. 3) Hybrid: optimistic parallel + reconciliation/merge step.

chris: From SLAs POV we need to surface tradeoffs clearly. If we do strict sequencing, per-request latency SLO will increase. For Hosted MVP we should default to best-effort and document failure modes.

maya: Proposal for roadmap MVP (parity across product/dev time):
- Offer parallel invokes by default with best-effort ordering.
- Require callers to pass idempotency_key for external side-effects.
- Provide an opt-in mode "sequential_consistency": available only on Dedicated/Private initially.
- Default retry_budget = 2, overall pipeline timeout = 15s.
