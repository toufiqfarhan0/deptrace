announcements

alexa (product): Quick GA announcement: Horizon Adaptive Ensemble is now GA on the Hosted API. Horizon lets you target cost or latency per-request and runs lightweight ensembles + reranking to match QoS. Rolling to us-west-2 and eu-west-1 first, global over 72h. Docs + quickstart: https://redwood.example.com/horizon-ga  :tada:

ben (eng-runtime): Short API summary: new endpoint POST /v2/ensemble. Use header X-RW-Ensemble: horizon and include {"strategy": "cost_target"} or {"strategy": "latency_target"} in the body. Example: {"model_candidates":["aeon-lite-7b","quantedge-4b-q"], "strategy":"cost_target", "budget_usd_per_1k": 0.50}. The service will shard, run candidate decodes, and do a fast rerank.

marta (devex): SDK snippet: client.ensemble.run({models:['aeon-lite-7b','quantedge-4b-q'], strategy:'cost_target', budget_usd_per_1k:0.5, stream:true})
Curl example:

```
curl -H "Authorization: Bearer $TOKEN" \
  -H "X-RW-Ensemble: horizon" \
  -H "Content-Type: application/json" \
  -d '{"model_candidates":["aeon-lite-7b","quantedge-4b-q"],"strategy":"cost_target","budget_usd_per_1k":0.5,"session_id":"ens-77"}' \
  https://api.redwood.com/v2/ensemble
```
