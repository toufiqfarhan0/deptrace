karim_infra: pipx uses its own interpreter unless you tell it which python to use. If you want pipx to use the poetry venv's interpreter use `pipx install --python $(poetry env info -p)/bin/python --editable .` or `poetry run pipx install --editable .`. That avoids picking a globally cached wheel for a different arch.
