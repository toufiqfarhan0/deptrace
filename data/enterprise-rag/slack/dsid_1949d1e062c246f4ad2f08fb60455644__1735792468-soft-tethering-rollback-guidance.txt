Devon: pseudo resolver snippet:
```py
# choose best variant based on pin metadata score
now = now_utc()
for v in variants:
    base = v.default_priority
    p = v.pin
    if p is None:
        score = base
    else:
        score = base + p.affinity_priority
        if p.soft_expiry and now > parse(p.soft_expiry):
            score -= (p.affinity_priority * 0.7)  # degrade, but don't drop to -inf
    v.score = score
return argmax(variants, key=lambda v: v.score)
```
