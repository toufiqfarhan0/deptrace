kevin: looks like the Go SDK default strategy for schema failures is to return a safe fallback to avoid crashing apps, but that's not okay for strict_output_schema when app expects the exact shape. we need consistent behavior across SDKs: either surface error or let app opt-in to fallback.

maria: immediate mitigation: I updated the sample to set `STRICT_OUTPUT_FAIL_FAST=true` env var that forces the SDK to return a 4xx to the app. That unblocks the partner.
