Anya: quick thought on making fallback decisions auditable and predictable across hosted/dedicated/private. proposing a minimal manifest addendum that lists 'allowed_ops', 'fallback_sources', and a compact 'observability_hint' so controlplane/ops aren't surprised.

Marcus: yes please. We've seen runtime try to fall back to a variant that needed kv-exchange and it failed silently. early reject is better than late failure.

Isha: For private installs, we must avoid requiring outbound telemetry. observability_hint should allow none|summary|stream and adapters must be able to advertise none.

Tom: Suggest 'allowed_ops' be an explicit list: generate, embed, kv_share, swap_variant. Runtime enforces deny rules based on trust_tier. If denied, return 409 + code ERR_OP_FORBIDDEN_BY_TRUST.

Anya: Minimal manifest example (for discussion) inside the message to avoid a separate doc:
```json
{"manifest_ver":"2","trust_tier":"hardware_isolated","allowed_ops":["generate","embed"],"fallback_sources":["local"],"observability_hint":"none","manifest_sig":"sha256:deadbeef","epoch":"2026-03-22T10:00:00Z"}
```

Isha: Also add a one-line 'audit_hint' (URN/URL) so adapters that can push audit blobs know where to send them. If absent, adapter must keep local immutable ledger entries.

Marcus: runtime rule: if trust_tier==hardware_isolated then disallow kv_share and swap_variant. SDKs should expose a clear typed error so callers can degrade. Also, controlplane must not attempt remote fallbacks if fallback_sources doesn't include 'controlplane'.

Tom: Ops: add a compact cb field like 'cb=errpct:5|min:50' encoded as a string to avoid structural changes. Controlplane will parse it for UI.

Anya: UI expectation: a 'fallback history' row per tenant showing timestamp, source (local|controlplane), op, and reason. If observability_hint==none, show "telemetry degraded" badge.

Isha: Testing: we need a dry-run mode where controlplane simulates fallback decisions using only metadata (no traffic switch) to estimate latency/cost. opt-in per tenant.

Marcus: manifest drift handling: include epoch + sig and a soft grace window. On mismatch emit 'manifest_mismatch' event; don't evict immediately.
