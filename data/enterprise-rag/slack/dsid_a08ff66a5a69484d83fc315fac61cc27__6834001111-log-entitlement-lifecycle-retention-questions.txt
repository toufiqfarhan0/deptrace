eli: revoke job pseudo:```python
def revoke_entitlement(ent_id):
    ent = acl_db.get(ent_id)
    if ent.status != 'active':
        return
    # 1 - disable SIEM subscription
    siem_api.delete_subscription(ent.subscription_id)
    # 2 - remove KMS grant / schedule key rotation
    kms.revoke_grant(ent.kms_grant_id)
    kms.schedule_key_rotation(ent.kms_key_alias)
    # 3 - trigger bucket scrubber for internal destinations
    if ent.destination == 's3_internal':
        scrubber.trigger(prefix=ent.bucket_prefix)
    # 4 - mark entitlement expired
    acl_db.update(ent_id, status='expired')
```
