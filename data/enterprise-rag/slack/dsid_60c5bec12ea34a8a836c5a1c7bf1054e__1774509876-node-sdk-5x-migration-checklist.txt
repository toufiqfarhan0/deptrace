sara: can we get a short checklist for release notes + quickfixes? i can copy into the migration guide.
alex: quick checklist i started: 1) auth: new AuthClient constructor + env var names, 2) streaming: use client.stream({}) -> new .streamingCreate() signature, 3) retries: maxRetries default dropped to 2, add explicit retry config if you relied on old behavior, 4) deps: drops support for node 12.
molly: is there a minimal code diff for auth? people keep opening tickets about "401 after upgrade"
raj: yep — old pattern:
```js
const Redwood = require('@redwood/sdk');
const client = new Redwood.Client({ apiKey: process.env.REDWOOD_API_KEY });
```
new pattern:
```js
const { AuthClient, RedwoodClient } = require('@redwood/sdk');
const auth = new AuthClient({ apiKey: process.env.REDWOOD_API_KEY_V5 }); // NOTE: env var rename
const client = new RedwoodClient({ auth });
```
alex: emphasize env var rename — many folks set REDWOOD_API_KEY in CI and hit 401s. mention fallback for one release: we accept REDWOOD_API_KEY if REDWOOD_API_KEY_V5 missing but warn.
jin: streaming example diff: old:
```js
const stream = client.stream({ model: 'rwd-1' });
stream.on('data', chunk => console.log(chunk.text));
```
new:
```js
const stream = client.streamingCreate({ model: 'rwd-1' });
for await (const event of stream) { // async iterator yields framed events
  if (event.type === 'delta') console.log(event.delta);
}
```
sara: do we need to call any helper to decode frames now? I saw some customers sending raw binary and failing.
raj: framing is same, but events are normalized. previously we emitted raw chunks; now we send structured events and you must check event.type. include a snippet to convert old handler to new one.
molly: retries: a bunch of customers depended on unlimited retries. what's our recommended migration note?
alex: recommend explicit retry policy in constructor:
```js
const client = new RedwoodClient({ auth, retry: { maxRetries: 5, backoffMs: 200 } });
```
call out the cost implications in the note.
sara: any deprecations to call out in SDK docs? like removed methods?
jin: remove: client.fetchModelListSync, client.rawStreamEvent. Deprecate: client.listModels (sync -> async).
