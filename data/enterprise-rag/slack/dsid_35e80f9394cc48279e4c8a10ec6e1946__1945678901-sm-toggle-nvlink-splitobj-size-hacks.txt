Ana: here's the minimal nvcc pattern I tested locally that reduced size a lot (only generating cubins for prod arches + one ptx fallback):
```
nvcc -O3 \
  -gencode arch=compute_86,code=sm_86 \
  -gencode arch=compute_90,code=sm_90 \
  -gencode arch=compute_90,code=compute_90 \# PTX fallback for newer cards
  -Xptxas "-v"
  -Xcompiler -fPIC
```
