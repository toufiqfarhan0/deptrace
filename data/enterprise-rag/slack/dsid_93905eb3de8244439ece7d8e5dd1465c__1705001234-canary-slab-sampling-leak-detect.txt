def slab_sample(prompts, slab_id, total_slabs, seed=42):
    random.seed(seed)
    start = int(len(prompts) * slab_id / total_slabs)
    end = int(len(prompts) * (slab_id+1) / total_slabs)

kevin rao: Agree. Quick fix: use hash-based slab assignment on fingerprint, e.g.:
```python
import hashlib
def assign_slab(prompt, total_slabs):
    h = hashlib.sha256(prompt.encode()).digest()
    return int.from_bytes(h[:4], 'big') % total_slabs
```
Then sample by assigned slab. Will be stable and avoid adjacency leakage.
