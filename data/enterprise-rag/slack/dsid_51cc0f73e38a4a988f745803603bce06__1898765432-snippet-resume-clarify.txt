noah: added three tiny snippets in the PR:

PYTHON:
```py
async def run(q):
  async for part in client.responses.stream(model='redwood-mini', input=q):
    handle(part)
await asyncio.wait_for(run(q), timeout=0.25)
```

TYPESCRIPT:
```ts
const ac = new AbortController();
const s = client.responses.stream({model: 'redwood-mini', input: q, signal: ac.signal});
let seen = 0;
for await (const p of s) { process(p); if (++seen >= 25) ac.abort(); }
```

GOLANG:
```go
ctx, cancel := context.WithTimeout(context.Background(), 250*time.Millisecond)
defer cancel()
// token may be empty string for first page
req.Query.Set("cursor", token)
stream, _ := client.StreamResponses(ctx, req)
for stream.Next() { ev := stream.Event(); handle(ev) }
```
