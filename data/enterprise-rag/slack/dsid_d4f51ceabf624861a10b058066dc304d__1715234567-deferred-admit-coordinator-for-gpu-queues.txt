alex: Quick design idea — a "deferred admit coordinator" that sits in front of the per-key token buckets and holds requests when GPU headroom is low. It would dole out short-lived "ephemeral burst" credits based on realtime headroom and queue pressure. Thoughts?

maria: Are we talking about a separate admission layer or augmenting the current tokenbucket service? how do we compute headroom? :thinking:

alex: Separate thin layer. Headroom = usable_gpu_seconds - estimated_inflight_seconds. Usable_gpu_seconds comes from fleet metrics (free gpus * median_batch_throughput). We already emit free_gpus per pool.

kevin: Fairness question — we can't let noisy orgs borrow all ephemeral credits. Need per-org escrow + decay. Maybe ephemeral credits are non-transferable and have short ttl.

sam: Implementation sketch: keep per-org token bucket as today, but have coordinator compute a global refill multiplier M = clamp(headroom_fraction * alpha, 0, 1). Each org's effective_refill = base_refill(org) * (1 + burst_factor * M). If M==0 no burst.

alex: yep, exactly. Example snippet we could wire into token service: ```

M = min(1, headroom_frac * 0.8)
effective_refill = base_refill * (1 + 1.5 * M)
// ephemeral credits issued with ttl=3s and non-transferable
```
