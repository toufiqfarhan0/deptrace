Fix suggestions to tell the customer / docs changes:
- Recommend using single quotes in *nix shells: `--data-raw '{"prompt":"hi"}'`
- For PowerShell, recommend using `--%` or `--data-binary` or a @' '@ heredoc to avoid quote mangling. Example:
```
# PowerShell safe
curl --data-binary @- https://... -H \"Content-Type: application/json\" --data-binary '{"prompt":"hi"}'
# or using a file: curl --data-binary @payload.json
```
