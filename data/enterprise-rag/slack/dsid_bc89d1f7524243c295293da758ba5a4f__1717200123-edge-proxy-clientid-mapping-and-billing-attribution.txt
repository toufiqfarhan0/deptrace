Dan King: We saw this class of bugs before when proxies normalize header encoding. Short-term mitigation: preserve original header as `X-RW-Client` and have metering prefer that if present. Longer-term: propagate a deterministic `req_id` from edge -> router -> metering so we can join reliably.

```
-- pseudo-SQL
INSERT INTO billing.events_fixed
SELECT m.* EXCEPT(client_id), coalesce(i.client_id, m.client_id) AS client_id
FROM metering.raw_events m
LEFT JOIN ingress.requests i ON i.req_id = m.req_id
WHERE m.ingest_time BETWEEN '2024-05-30' AND '2024-05-31'
  AND m.client_id = 'anonymous'
  AND i.client_id IS NOT NULL;
```
