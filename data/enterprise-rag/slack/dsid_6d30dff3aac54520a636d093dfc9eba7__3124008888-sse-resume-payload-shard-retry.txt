linus: Long-term fix proposal (patch): tie resume tokens to (session_id, generation_id, last_ack_offset) and on reconnect check: if reconnect.offset <= session.last_acked_offset -> treat as already-acked and resume without re-generating. If reconnect references generation_id that's still active, attach to same generation rather than spawn new one. Pseudo: 
```python
# on reconnect
state = get_session_state(session_id)
if resume.generation_id == state.active_generation_id:
    # attach socket to same inflight generation 
    attach_stream(state.active_generation)
elif resume.offset <= state.last_acked_offset:
    # client already saw this, skip re-gen and fast-forward
    send_resume_ack(stream, state.last_acked_offset)
else:
    # start new generation from resume.offset but ensure idempotency key
    start_generation(session_id, resume.offset, idempotency_key=res.token)
```
