sam: attached quick sketch of script I ran locally:
```
# synthesize tokenizer_config.json
from pathlib import Path
import json
j = json.loads(Path('tokenizer.json').read_text())
conf = {'special_tokens_map': {}, 'added_tokens': []}
# heuristics: look for <s>, </s>, <pad>, <unk>
for t in ['<s>','</s>','<pad>','<unk>']:
    if t in j.get('model', {}).get('vocab', {}):
        conf['special_tokens_map'][t.strip('<>/')] = t
Path('tokenizer_config.json').write_text(json.dumps(conf))
```
