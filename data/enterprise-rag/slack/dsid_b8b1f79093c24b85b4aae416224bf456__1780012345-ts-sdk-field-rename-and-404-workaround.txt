maria: Quick fetch workaround (paste into your server route):
```
const res = await fetch('https://api.redwood.ai/v1/generate', {
  method: 'POST',
  headers: {
    'Authorization': `Bearer ${process.env.REDWOOD_KEY}`,
    'Content-Type': 'application/json'
  },
  body: JSON.stringify({ model: 'redwood-1.1', input: prompt })
});
const payload = await res.json();
```
This bypasses the SDK and talks to the new endpoint directly.

maria: One more tip: until you upgrade you can add a compatibility shim in your app to translate old calls to the new endpoint: 
```
// compatibility-shim.ts
export async function responsesCreate(client, opts) {
  // map old opts -> new API shape
  const mapped = { model: opts.model || opts.model_name, input: opts.prompt || opts.text };
  return client.request('POST', '/v1/generate', mapped);
}
```
This avoids changing call sites quickly.
