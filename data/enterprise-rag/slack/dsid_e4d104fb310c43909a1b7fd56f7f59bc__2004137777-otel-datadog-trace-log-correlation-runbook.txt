Noor Ahmed: shim example (python):
```python
from opentelemetry import trace
import logging

tracer = trace.get_tracer(__name__)
logger = logging.getLogger('infer')

def handle_request(req):
    ctx = extract_w3c(req.headers)
    with tracer.start_as_current_span('infer.request', context=ctx) as span:
        logger.bind(trace_id=span.get_span_context().trace_id)
        # process
```

```yaml
  datadog:
    api:
      key: "${DD_API_KEY}"

    traces:
      receivers: [otlp]

      exporters: [datadog]
```
