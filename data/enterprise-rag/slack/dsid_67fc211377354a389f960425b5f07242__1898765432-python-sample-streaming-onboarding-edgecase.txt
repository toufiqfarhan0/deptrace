Kevin: probably due to our SSE/chunked read loop not noticing EOF when Cancel is called. Windows sockets sometimes return 0 differently?

Marta: Is this specific to sync API or async too?

Jordan: both. Async version: `async for event in client.stream_chat(...):` — when caller cancels the task, the generator's finalizer isn't closing the underlying socket on Windows, so the process waits for TCP timeout. On Linux signals it usually unwinds fine.

Priya: do we have a test that covers canceling the iterator? I thought we had one for graceful close but maybe only for normal EOF.

Kevin: we have tests for `aclose()` but not for external task cancellation. Another wrinkle: type hints use `Iterator[str]` for sync and `AsyncIterator[str]` for async, but some users pass the generator to frameworks expecting `Iterable` and that can keep references alive, delaying cleanup.

Marta: ok can we short-term add a context manager on the client that forces close on __exit__? that would at least help the sample-app docs.

Jordan: sample-app already does `with client.stream(...) as s:` in one variant, but the example the onboarding doc points to uses `for chunk in client.stream(...):` without `with`. New onboarders copy/paste that and hit the hang.

Priya: proposed fix: update the sample to use explicit context manager AND add a finalizer that calls `transport.close()` from `weakref.finalize(self, ...)`. Also add a platform-specific path to interrupt `recv()` on Windows by calling `shutdown(socket.SHUT_RD)` before close.

Kevin: sounds reasonable. two follow-ups: 1) add a mypy-friendly typing overload so `stream()` returns a `ContextManager[Iterator[str]]` for sync and `AsyncContextManager[AsyncIterator[str]]` for async (helps editor hints). 2) add a tiny e2e test that spawns the stream, cancels after first chunk, and asserts the process finishes within 1s on CI (use loopback).

Marta: +1. be careful with forcing `shutdown()` — we need to ensure we don't raise in normal code paths. wrap in try/except and only call if socket is open.
