andy c: If you want the quick PromQL snippets we use for alerts — p95 TTFT over 200ms (prod) looks like this:
```
histogram_quantile(0.95, sum(rate(request_latency_bucket[5m])) by (le, service, model))
```
And tokens/sec per model (5m avg):
```
sum by (model) (rate(tokens_emitted_total[5m]))
```
Defaults we usually suggest: p50 < 80ms, p95 < 200ms, p99 < 400ms for prod small models. For large context models bump by ~1.5x.
