leia: Heads-up — new users hitting the python sample app during onboarding report a crash when tool functions return dataclass objects on the async path. Repro on sample-app-prod.

leia: Quick repro snippet from the sample app (async):
```py
from dataclasses import dataclass
from redwood import AsyncClient

client = AsyncClient(api_key=ENV_TOKEN)

@dataclass
class Item:
    id: int
    name: str

async def main():
    res = await client.call_tool(name="parse_item", input={"raw": "42 Widget"}, response_schema=Item)
    print(res)
```

omar: Is the returned object actually a dataclass instance? Our serializer supports dataclasses on sync path.

leia: Yes. We map DB -> dataclass then return. If we change to returning a dict everything is fine.

devx-sre: I dug into the logs. Two things that look related: (1) the async serializer is run on a threadpool without our plugin hooks so dataclass handling is missing; (2) sometimes a token-refresh race leads to a 401 and the retry wrapper bails out early and leaves a partially-constructed response that triggers the serializer. Example log snippet:
```
[2026-03-20T17:10:12Z] http /v1/toolcall -> 401 token_expired
[2026-03-20T17:10:12Z] auth refresh -> 200
[2026-03-20T17:10:12Z] retry: header-missing -> abort
[2026-03-20T17:10:12Z] toolcall serializing -> TypeError
```

jess: Workaround for sample-app: explicitly convert dataclass before returning, e.g. `return asdict(item)`. It's ugly but works for onboarding. We should document it until a patch lands.

sam: Would it make sense to add a CI matrix entry that runs the sample app with both sync/async toolcall and with dataclass/dict outputs so this doesn't regress?

devx-sre: Agree. Plan I propose:
- Patch async serializer to preserve runtime hooks when running in executor OR avoid running coercer in threadpool.
- Harden token-refresh retry for toolcall to always re-try the request (idempotency header handling) or ensure we surface auth failure separately from serialization errors.
- Add unit + e2e tests in sample-app CI matrix (sync/async x dataclass/dict).
