owen: Aiohttp/httpx use SSLContext under the hood; passing `verify` alone might not wire into the SSLContext when a proxy transport is used. Workarounds I've used: set `SSL_CERT_FILE` or build an ssl.SSLContext and pass it to the client. Eg:
```python
import ssl
sslctx = ssl.create_default_context(cafile="/etc/ssl/certs/redwood-ca.pem")
# httpx-style transport example (pseudo)
client = AsyncClient(..., transport=AsyncHTTPTransport(ssl=sslctx))
```
