claire: Rust snippet should be <=20 lines. Suggest the minimal example below for the quickstart:
```rust
use redwood::{Client, Config};
fn main() -> Result<(), Box<dyn std::error::Error>> {
  let mut cfg = Config::default();
  cfg.kms_transport = "unix".into();
  cfg.kms_socket = "/var/run/kms.sock".into();
  let client = Client::new(cfg)?;
  client.health_check()?;
  Ok(())
}
```
