```
POST /orders -> 401 token_expired
app: start retry request (client retry)
sdk(py): starting token refresh attempt 1 -> sleep 100ms (no jitter)
sdk(py): attempt 2 -> sleep 200ms
app: retry sends POST /orders -> no Idempotency header
sdk(py): refresh succeeded during app retry
backend: two orders created within 50ms
```

paul: so two independent retries (app + sdk) again. Difference is timing due to backoff. node was fine because jitter spread refresh out and avoided collision.
