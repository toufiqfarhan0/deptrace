tariq: This matches a known breaking change we shipped in 1.26: we renamed the `stop` param to `stop_sequences` internally and removed the old alias. Instead of a clear deprecation, Python raises TypeError at call-time. Our client-side retry policy treats TypeError as retryable in some wrapper code, so it retried the call and ended up sending the request twice. That can explain duplicate billing.
