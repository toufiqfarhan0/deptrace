Megan (CS): --- START CHECKLIST ---
- Run the 5-min health sweep: open Console -> Usage, check last 7d token trends, and Alerts tab for any spikes. If tokens down >35% vs baseline, mark risk.
- Verify streaming endpoints used: look for `stream=true` in recent calls; if switching to polling, note latency regression.
- Check recent errors: search logs for 5xx / timeout patterns. If >3% error rate, escalate to eng-oncall.
- Onboarding tasks: confirm whether demo dataset import, auth setup (API key + IP allowlist), and prefill config completed.
- Enablement: confirm customer saw the 1-hr workshop recording and received the quickstart link. If not, schedule a 30-min pairing session.
- Renewal signals: flag if primary contact inactive >14 days, exec sponsor absent, or major product change request pending.
- Capture feedback: send 3-question pulse: 1) What worked? 2) Biggest pain right now? 3) Would you recommend us? (1-5). Paste verbatim comments into the ticket.
- Immediate actions: assign owner, set due date, and record expected outcome (reduce latency, recover tokens, complete enablement).
--- END CHECKLIST ---
