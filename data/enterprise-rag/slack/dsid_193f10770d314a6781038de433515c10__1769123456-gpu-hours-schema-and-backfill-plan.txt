data_eng: mitigation formula (short):
- gpu_hours_estimate = SUM(gpu_seconds) / 3600 / sample_rate
we default sample_rate=0.1 for the v2 emitter in prod. so multiply by 10 after dividing by 3600.

Example event schema snippet from v2: 
```json
{
  "event_type": "usage",
  "timestamp": "2026-03-13T02:05:12Z",
  "gpu_seconds": 12345,
  "sample_rate": 0.1,
  "region": "eu-west-2",
  "instance_type": "a100-80gb"
}
```

Suggested on-the-fly SQL for dashboards (quick patch):
```sql
SELECT region,
       SUM(gpu_seconds)/3600.0 / NULLIF(AVG(sample_rate),0) AS gpu_hours_estimate
FROM usage_events_v2
WHERE ts >= current_date - interval '7 days'
GROUP BY region;
```
