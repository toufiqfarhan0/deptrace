maria: Quick heads-up — SDK v11.0 will cut Wed EOD. Breaking/deprecation summary and migration notes below. TL;DR: auth header normalization, default retry backoff tightened, streaming event rename, Go module bump, Python sync client removed. Please read and flag concerns.

josh: Thanks — where's the canonical upgrade checklist? link?

maria: Put it inline for now. Full doc coming to /eng and release notes. Quick checklist:
• Update import/module paths
• Auth: prefer Authorization: Bearer <token> (old 'x-redwood-key' deprecated)
• Retry: default attempts 5 -> 3, +exponential jitter; opt-in to old behavior via ClientConfig.retry.max_attempts
• Streaming: event name 'data' -> 'payload_chunk' and 'done' -> 'stream_end'
• Python: sync 'Client' removed; use 'AsyncClient' or the provided sync wrapper
• Node: streaming switched to async iterator; update for-of loops

josh: Example snippets?

maria: Node auth change:
```
// old
const client = new Redwood({ apiKey: process.env.REDWOOD_KEY });

// new
const client = new Redwood({ authorization: `Bearer ${process.env.REDWOOD_TOKEN}` });
```

maria: Python sync -> async example:
```
# old
from redwood import Client
c = Client(api_key=...)
resp = c.generate(...)

# new
from redwood import AsyncClient
c = AsyncClient(authorization="Bearer ...")
async with c:
    resp = await c.generate(...)
```

nora: For Go, migration involves updating module path and KV cache API? Any breaking changes there?

maria: Yes — kv cache rename: `KV.Get` -> `KV.Fetch` (returns (value, found, err)). Also module path bumped to v11, so run `go get github.com/redwood-inference/sdk-go/v11@latest` and update imports.

alex: Will existing tokens continue to work or do we need rotation?

maria: Existing tokens still valid. Deprecation window: 90 days for the old x-redwood-key header; the SDK will emit a warn log when it sees that header. Recommend rotating to Bearer before EoD+60.
