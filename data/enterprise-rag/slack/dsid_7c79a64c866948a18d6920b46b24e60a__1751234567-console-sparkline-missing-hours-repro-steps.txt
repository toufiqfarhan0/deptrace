tess: Digging in — 06:00 partition contained a malformed event (tenant_id was null) which caused the upsert to fail for that batch. We had an unhandled exception path that aborted the whole hour group. I patched upsert to treat null tenant_id as skip and reran a filtered replay for 06:00.
```
-- simplified upsert (patched to skip null tenant_id)
INSERT INTO hourly_rollups (tenant_id, hour_bucket, tokens) 
SELECT tenant_id, hour_bucket, sum(tokens) FROM staging_events
WHERE tenant_id IS NOT NULL
GROUP BY tenant_id, hour_bucket
ON CONFLICT (tenant_id, hour_bucket) DO UPDATE SET tokens = hourly_rollups.tokens + EXCLUDED.tokens;
```
