jon: quick dump of differences i see:
```
# old tokenizer (sage-mini-v1)
BOS -> 1
EOS -> 2
PAD -> 0
# new tokenizer (v2)
BOS -> 1001  # sentinel-style BOS
EOS -> 1002
PAD -> 50280
```
Two implications: (1) prompt templates that assume PAD==0 will misalign lengths; (2) KV cache indexing is fine but our prompt trimming code checks for EOS==2.
