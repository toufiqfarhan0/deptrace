sasha: code sketch for route config (Pseudocode):

```
route: /v1/generate
match: method: POST
headers: {"x-client-tier": ["free","paid"]}
actions:
  - alias: generate-big (paid)
  - alias: generate-small (free)
  - pin: none
  - fallback: {enabled: true, order: [generate-small, generate-big]}
capabilities_required: ["streaming","chat-completions"]
```
