sam: weird. pointer-events layering is probably from the sparklines overlay. quick fix: set pointer-events:auto on .legend-toggle and z-index above sparklines. but we should avoid breaking touch targets
tara: for smoothing, maybe we toggle smoothing only on hover/expand. i don't want tiny charts to hide peaks by default. default should be 'no smoothing' in compact mode and a small smoothing toggle in the expanded panel
jess: UX detail: show a micro-hint icon after the unit label that opens a mini legend explaining P50/P95/P99. users frequently confuse '95th' with 'P95' naming. microcopy: "P95 latency (95th percentile)" in the tooltip, but keep label simple as "P95" in tight spaces
leah: outlier handling idea: render faint markers for outliers but collapse their tooltips into a single inline summary at the right edge of the sparkline: e.g., "3 spikes 30s ago7". clicking that shows a list view with timestamps. keeps chart itself clean
sam: implementation note: avoid creating DOM nodes per-point in compact mode. use background-image or canvas overlays for visual flags and a single accessible button element for screen readers
accessibility-bot: automated check: ensure that collapse buttons have aria-haspopup="dialog" and aria-expanded toggles. screen-reader label should include unit and count (e.g., "Sparkline, P95 420ms, 2 spikes, press enter to open details")
tara: for keyboard nav, one tab should land on the whole sparkline control, not each marker. use role="button" and aria-controls to open a popover with focus trap for details
jess: copy tweak: replace "View details" with "Open timeline" across compact variants. product says it's clearer when action reveals sequence data
leah: analytics: change event "sparkline_point_tooltip" -> "sparkline_compact_summary_open" and emit counts when opened. we need to keep heatmap telemetry to know if smoothing was toggled
sam: dev plan: 1) legend collapsed + tabbable chevron, 2) compact smoothing off by default, add toggle in expanded view, 3) aggregate outlier control with aria-friendly label, 4) microcopy fixes for P95 vs 95th. estimate 2 dev days + design QA
