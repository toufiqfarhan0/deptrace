Jia: I also ran a one-off backfill to populate missing cost rows so dashboards refresh immediately:
```
INSERT INTO token_costs (org_id, day, tokens, price_per_token, cost)
SELECT te.org_id, te.day, SUM(te.tokens), COALESCE(pm.price_per_token,0), SUM(te.tokens) * COALESCE(pm.price_per_token,0)
FROM token_events_raw te
LEFT JOIN price_map pm ON te.model = pm.model
WHERE te.day >= '2026-03-15'
GROUP BY te.org_id, te.day, COALESCE(pm.price_per_token,0);
```
Backfill created cost rows for the 12 affected orgs.
