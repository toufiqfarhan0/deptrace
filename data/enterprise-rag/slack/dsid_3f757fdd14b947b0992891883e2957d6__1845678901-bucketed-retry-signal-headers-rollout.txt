maya: tighten. keep 429 = quota, 503 = capacity/backpressure, 424 = downstream dependency failures. add three headers: `x-rw-reason`, `x-rw-retryable`, `x-rw-retry-hint` (seconds or textual).

sofia: console needs deterministic badge buckets: OK / THROTTLED / DEGRADED / UNAVAILABLE. copy must be very short (<80 chars) and actionable when possible.

maya: mapping sketch:
```
429 + x-rw-reason=quota -> badge: THROTTLED, x-rw-retryable=true, x-rw-retry-hint=Retry-After or secs
503 + x-rw-reason=backpressure -> badge: DEGRADED, x-rw-retryable=false, no retry_hint
424 + x-rw-reason=downstream -> badge: UNAVAILABLE, x-rw-retryable=false, retry_hint="contact support"
5xx generic -> badge: UNAVAILABLE, retryable=false, retry_hint="try later"
```
