Anya R.: per-shard start/finish + bytes streamed + chosen fallback path (index-first vs stream-first). also a small error tag when we fall back to mmap or remote-read.

Matt S.: prefer counters + histos. counters: shards_requested, shards_completed, shards_failed, fallback_count. histos: shard_stream_latency_ms, bytes_per_shard. tags: model, shard_id, node_zone, warmup_type. avoid high cardinality (shard_id only for traces not metrics)

Tess O.: note: shard_id as a tag will blow up TSDB. maybe include shard_bucket (hash%100) as metric tag and full shard_id only in logs/traces. also think about labeling 'load_strategy' = {stream,index,mmap}

interface HandoffObserver {

}
