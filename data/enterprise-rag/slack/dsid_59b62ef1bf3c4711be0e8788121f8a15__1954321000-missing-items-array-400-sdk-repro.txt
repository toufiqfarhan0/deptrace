Mike (eng-runtime): Thanks — I can repro locally with SDK 2.3.1. There's a serialization bug that turns empty arrays into the string "[]" and ints into strings in some codepaths. Server schema validation rejects types. Server logs show: 
```
WARN validate_request 1954321000 request_id=abc-123 err="candidates: expected array, got string"
```
I'll open a quick branch to coerce stringified arrays/numbers for a short window, but we should avoid silently swallowing other malformed payloads.
