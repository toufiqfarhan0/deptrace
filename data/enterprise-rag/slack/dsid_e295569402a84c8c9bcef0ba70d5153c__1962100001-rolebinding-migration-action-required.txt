Maria (Backend): Example old vs new please \u2014 want to patch a couple of microservices today.

Emma (Security): Old -> New example:

Old:
```
role_map:
  "team:eng:frontend": "app:frontend-owner"
  "team:sre": "*"
```

New:
```
roleBindings:
  - principal: "group:eng-frontend"
    roles:
      - "app:frontend-owner"
  - principal: "group:sre"
    roles:
      - "monitor"
      - "operator"
```

Notes:
- Prefer groups or scoped principals instead of wildcards.
- If you relied on `*` for admin, switch to explicit roles and add a small ACL review.
