Raj (Engineering): Electron webviews are notorious for subtle differences. Regarding the `+` -> space: `%2B` is the safe encoding for plus. If any component performs `decodeURIComponent` early then re-encodes with application/x-www-form-urlencoded semantics, `+` can become a space. Make sure no proxy/plugin is performing URL decode+re-encode on the query string.
Mina (Infra): On nginx ingress common gotcha: `proxy_set_header Host $host:$server_port;` will include the internal port. Prefer `proxy_set_header Host $http_host;` or set `proxy_set_header Host $host;` and ensure the load balancer preserves the original host header. Also ensure `proxy_pass` doesn't include a trailing slash that rewrites the querystring. Example fix:
```
proxy_set_header Host $http_host;
proxy_set_header X-Forwarded-Proto $scheme;
proxy_set_header X-Forwarded-Port $server_port;
proxy_pass http://upstream;
```
