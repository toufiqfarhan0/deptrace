marta: Layout: compact 16-byte header per bucket, fixed block slots per bucket (configurable), separate free-list per bucket. Hash bucket = (seq_id >> slot_shift) % N_BUCKETS.

marta: Good call. I added an LRU ring per bucket + a global aging pass every 10s to avoid hot-item scattering. Eviction is local-first; only if bucket full and all entries aged -> global steal from low-usage buckets.

ciara: Can you paste the alloc path? I want to compare to slab-style we used.

marta: Sure, pseudo: ```
alloc_slot(seq):
  b = bucket_for(seq)
  if b.free_slots > 0: return b.pop_free()
  if b.find(seq): return replace_existing()
  if b.age_top() > AGE_THRESH: return b.evict_lru()
  return global_steal()
```
