--- paste-ready snippets ---

```
IC self-review (3 lines):
1) Top outcome this sprint: shipped X that increased Y by Z%.
2) What I learned / one improvement I made: automated flakiness in CI -> -30% test delays.
3) Roadblock / ask: need cross-team API design sync; assigned to @Sam. confidence: high

IC note (platform work):
1) Top outcome: reduced p99 latency for batch inference by 18%.
2) Impact metric: cost per 1M requests down 12%.
3) Ask: capacity for deeper profiling next sprint. confidence: med

IC reflective (growth focus):
1) Skill developed: led design review for caching strategy.
2) Concrete result: fewer cache misses on 60% traffic flows.
3) Next step: mentor rotation for junior devs. confidence: low

Manager check-in (quick):
1) Observed impact: removed blocker on X, enabled Y team to ship.
2) Coaching note: suggest pairing on system tests next week.
3) Risk flag: integration test flakiness persists; consider canary.

Manager async comment (one-liner):
Quick win: great cross-team coordination on infra rollout — helped reduce deployment friction. :thumbsup:

Risk / block prompter (1 line):
If you see >2 blocked tasks because of external dependency, escalate to me and propose mitigation.

Simple confidence rubric (use inline):
- high = expect outcome met without help
- med = need 1-2 syncs
- low = needs blocker removal or scope change
```
