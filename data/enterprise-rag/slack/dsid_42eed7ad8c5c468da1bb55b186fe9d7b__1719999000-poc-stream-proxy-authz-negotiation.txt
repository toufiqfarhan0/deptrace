aj: On Node/TS side try configuring an http.Agent keepAlive + longer socket timeout. Example: 

  const keepAliveAgent = new http.Agent({ keepAlive: true, keepAliveMsecs: 60000 });
  fetch(url, { agent: keepAliveAgent, timeout: 120000 });

and increase SDK retry/backoff: 
  retries: { maxAttempts: 6, factor: 2, minTimeoutMs: 500 }

Also for streaming we recommend small chunk flushes so proxies don't buffer: set streaming.chunkSize ~16kb.

kevin: For Python requests use:
