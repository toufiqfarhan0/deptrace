tj_engineer: I tried to repro locally. Posting my steps:
```
# send as-is (payload.json contains raw cp1252 bytes)
curl -v -H 'Content-Type: application/json; charset=utf-8' -d @payload.json https://api.redwood.com/v1/rerank
# result: 400/500 with utf8 decode error

# quick workaround that fixed it on my machine
iconv -f cp1252 -t utf8 payload.json > payload.utf8.json
curl -v -H 'Content-Type: application/json; charset=utf-8' -d @payload.utf8.json https://api.redwood.com/v1/rerank
# result: 200 OK, normal scores
```
So the ingress expects valid UTF-8. If clients send legacy encodings, we fail.
