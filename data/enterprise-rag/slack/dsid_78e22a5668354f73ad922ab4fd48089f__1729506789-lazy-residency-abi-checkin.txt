sam: agree we should avoid ABI churn. what's the smallest visible change we can expose that lets runtime do async demote/offload without callers reworking tensors?

leo: one option: introduce an opaque ReserveHandle that callers can opt into. default allocation path remains unchanged. reserve() returns NULL on old callers, runtime treats NULL as legacy eager-residency. new callers can use reserve+async_demote to hint.

rachel: curious about fragmentation: if callers reserve a region then release later, could that make the heap more fragmented? how do we compact?

eva: good point. proposal is soft-reserve: reserve() does not pin pages, it just records logical ownership/hint. async_demote() moves KV pages to host when safe and records a demote token. reclaim is cooperative: allocator exposes reclaim_candidates() and the runtime can trigger compaction heuristics outside SLO windows.

sam: can you show the minimal API sketch?

leo: sure, rough pseudocode:
```c
// minimal additions, opaque to old clients
typedef struct ReserveHandle ReserveHandle;
ReserveHandle* reserve(size_t bytes); // NULL == legacy path accepted
int async_demote(ReserveHandle* h, DemoteOptions* opts); // 0 == accepted
int release_reserve(ReserveHandle* h);
```

rachel: demote semantics? does async_demote block until pages are migrated, or just schedule?

eva: schedule only. caller gets a DemoteToken which can be polled. we want non-blocking in-path. the token also carries a compactable_hint bit so compactor knows safe candidates.

sam: how about backward compatibility with older runtimes? if a new client calls reserve() but the runtime doesn't understand it, we should degrade gracefully. maybe reserve() returns a special code indicating feature unsupported and client falls back to old allocate-and-pin behavior.

leo: exactly. implementation detail: runtime will advertise feature flags via /info endpoint; clients can query at startup and choose fast path vs conservative path. also runtime should accept reserve() and return NULL if unsupported to keep ABI stable.
