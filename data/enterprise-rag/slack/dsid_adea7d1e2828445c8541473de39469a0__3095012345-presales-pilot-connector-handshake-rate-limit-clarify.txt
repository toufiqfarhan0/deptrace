Tom (runtime): paste below — super tiny pseudocode they can adapt:
```
max_retries = 5
backoff = 0.2  # seconds
for attempt in range(max_retries):
  resp = post('/v1/stream/handshake', body)
  if resp.status == 200:
    break
  if resp.status == 429:
    sleep(backoff * (2 ** attempt) * (1 + random()*0.5))  # jitter
    continue
  else:
    raise Exception(resp)
```
