aj: For vitest, try adding deps.inline for the SDK so Vite transforms it: in vitest.config.ts
```ts
import { defineConfig } from 'vitest/config'
export default defineConfig({
  test: {
    environment: 'node',
    deps: { inline: ['@redwood/inference'] },
    transformMode: { web: [/\.[jt]sx?$/] }
  }
})
```
