morgan: two ways: install the matching full CUDA toolkit (preferred) or create a symlink temporarily if you know the actual file name. example symlink (not ideal long-term):

maria: and add cmake flag to bake rpath: `-DCMAKE_BUILD_RPATH=/usr/local/cuda-12.2/lib64` so the binary finds libs at runtime. Also check `-DCMAKE_CUDA_ARCHITECTURES` (e.g., 80 for A100) to avoid weird PTX-only builds.
