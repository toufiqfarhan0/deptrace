Ben: Seen that. Two practical fixes we use internally: (A) spawn a goroutine to forward tokens to a channel and select on ctx.Done(), then call iter.Close(ctx) on cancel; (B) create a new Generator/transport for the retry (safe but higher overhead).

Ravi: Can you paste the small non-blocking pattern?

Ben: Sure, compact version:  
```go
func consumeSafe(ctx context.Context, iter sdk.Iterator) (string, error) {
  tokCh := make(chan string)
  done := make(chan struct{})
  go func() {
    for t := range iter.Stream() { tokCh <- t }
    close(done)
  }()
  var out string
  for {
    select {
    case <-ctx.Done():
      iter.Close(context.Background()) // force cleanup
      return "", ctx.Err()
    case t := <-tokCh:
      out += t
    case <-done:
      return iter.Result(), nil
    }
  }
}
```
