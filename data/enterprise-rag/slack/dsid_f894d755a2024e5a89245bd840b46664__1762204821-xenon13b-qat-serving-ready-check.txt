Priya S.: re: tokenizer — the HF tokenizer for xenon has merged tokens that break our instruction prefix detection. Quick fix is to force-add the tokens and use the fast tokenizer. Example patch for model-config: 
```yaml
model:
  name: xenon-13b-qat
  path: s3://redwood-models/xenon/13b/qat/v2
  tokenizer:
    use_fast: true
    special_tokens: ["<instr>", "<sep>"]
```
If `use_fast` falls back to the python backend we'll lose ~20-30% throughput in our perf baseline.
