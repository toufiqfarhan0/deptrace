Raj: Some quick technical notes:
- per-event signing approaches: asymmetric signatures (ECDSA/RSA) are best for external verification; HMAC only works if verifier shares key.
- signing every event via KMS/HSM has latency and cost implications. Consider batching or Merkle approaches.
- canonicalization is critical — otherwise signatures won't verify across languages. We should pick a standard (e.g., RFC8785 JSON canonicalization) and lock fields for signing.
Carmen: Contract flags: if we promise signed events + delivery/retention SLA, we must add an addendum to the contract/TOS. Also need terms around key compromise, indemnity, and acceptance of auditor artifacts.
