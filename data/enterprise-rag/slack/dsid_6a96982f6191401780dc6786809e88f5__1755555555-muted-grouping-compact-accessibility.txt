design

maya: quick idea after the SR pairing: what if suppressed channels are grouped under a compact "Muted channels" header in dense lists? sketch: https://redwood-internal.screenshots/muted-group.png

anya: I like grouping for visual declutter. concern: discoverability of per-channel actions (snooze, preview). group header needs clear affordances: expand, unsuppress all, and a way to pin specific channels to remain visible.

leah: Accessibility note: when a user tabs to the group header it should announce e.g. "Muted channels, 4 items, collapsed". On expand, move focus into the first item and announce "expanded, 4 items".

mike: Implementation: keep per-row controls inside the expanded list. preview loads only on explicit expand to avoid noise. ensure visual badges are aria-hidden if duplicated in aria-label.

jordan: For SR copy, prefer verb phrases: announce state as "notifications muted" not a lone badge. counts should be "2 recent messages" when relevant.

preeti: Copy variants: "Muted channels" vs "Suppressed channels"; "Muted" reads friendlier but we must be consistent across the app. I'll draft both for localization review.

ux-bot: Suggested markup (compact):
```html
<div role="region" aria-label="Muted channels, 4 items" tabindex="0">
  <button aria-expanded="false" aria-controls="muted-list" aria-label="Show muted channels">Show muted channels</button>
  <ul id="muted-list" hidden>
    <li role="listitem" tabindex="0" aria-label="Database Alerts, Critical, notifications muted, 2 recent messages">...</li>
  </ul>
</div>
```

leah: Also add an aria-live on the group header to announce new-message counts when collapsed (e.g., "Muted channels, 4 items, 1 new"). keep aria-live only on header, not per-row, to avoid repeated announcements.

maya: UX tradeoff: allow a per-user preference "Show muted channels inline" for power users who don't want grouping. pinned channels bypass grouping. pinned items should include "pinned" in aria-label.

mike: Visual polish: small padding increase in dense mode prevents clipping at large zoom. add prefers-reduced-motion support for expand animation.

anya: I'll prototype grouped variant in Figma and add acceptance criteria to INF-2120: group header announcements, focus move on expand, preview aria-live-only, verb-phrase state, pin behavior, copy variants. tagging @jordan @preeti for review.
