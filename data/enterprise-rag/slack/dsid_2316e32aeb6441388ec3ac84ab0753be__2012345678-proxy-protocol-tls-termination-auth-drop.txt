Lin (eng-platform): yes — draft checklist:
- Ensure LB termination mode documented (TLS vs passthrough) and guidance for when to use passthrough with oauth proxies.
- If using AWS NLB with PROXY protocol, ensure Service annotation `service.beta.kubernetes.io/aws-load-balancer-proxy-protocol: "*"` and set istio ingressgateway `listeners.use_proxy_protocol: true` on the Envoy listener.
- Audit node-level iptables/sidecars: `iptables -t nat -L PREROUTING` and `ss -tnp | grep <proxy_pid>`; look for transparent proxies that may mutate headers.

- If using an oauth callback dance, verify that the callback and subsequent proxied requests preserve the same connection semantics or use explicit re-auth on each request.
