dee: repro steps I used locally: 1) start simple http server that accepts chunked responses and then closes socket after 15s, 2) run curl as above with `--no-buffer`, 3) see `recv() got EOF` on client side and our gateway returns 502. Example server (node):

```
const http = require('http');
http.createServer((req, res) => {
  res.writeHead(200, {'Transfer-Encoding': 'chunked'});
  res.write('data: part1\n\n');
  setTimeout(() => { res.end(); /* or force socket.destroy() to simulate broken pipe */ }, 15000);
}).listen(8080);
```

Then `curl -N` shows initial chunks then connection closes, gateway logs 502 and metrics increment 5xx.
