sophia: yep, installer race. If two `redwoodctl config ensure` run concurrently they both attempt to write the profiles file. One might create an empty file then fail to write JSON. Workaround: run installer sequentially or set REDWOODCTL_CONFIG_DIR to a unique path per shell.

erin: workaround that fixed it for me: deleted ~/.config/redwood/profiles.json, then ran `redwoodctl login --headless --profile=erin-work --token-file=~/.config/redwood/erin.token` and then `redwoodctl config merge --file ~/.config/redwood/erin.token --into-profile=erin-work` (ugly but unblocked).
