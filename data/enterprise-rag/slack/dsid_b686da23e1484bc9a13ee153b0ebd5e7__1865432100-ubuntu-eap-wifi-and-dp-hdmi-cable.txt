tom-it: ok that helps. two follow-ups: 1) we require the CA cert to be set for PEAP connections — on desktop you can either point the connection to the CA .pem file or set "no CA" to false (not recommended). grab the CA at https://intranet.redwood/certs/redwood-enterprise-ca.pem and save to /etc/ssl/certs/redwood-enterprise-ca.pem then edit the connection:
```
nmcli connection show
nmcli connection edit "Redwood-Enterprise"
# in the editor: set 802-1x.ca-cert /etc/ssl/certs/redwood-enterprise-ca.pem
save
quit
sudo systemctl restart NetworkManager
```

tom-it: 2) if the GUI still acts up, try creating the connection via nmcli with explicit fields; i can paste a one-liner if needed.
