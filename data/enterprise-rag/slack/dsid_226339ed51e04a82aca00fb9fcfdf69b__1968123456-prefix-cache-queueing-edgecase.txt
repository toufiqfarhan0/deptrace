Maria P: Kernel selection angle: some quantized kernels have an up-front transform cost that scales with context length (even if KV cache avoids much compute). So although uncached tokens are few, choosing a kernel optimized for long sequences can add fixed latency. If packing ignores that, we end up doing small batches with heavyweight kernel path.

Maria P: We should: (a) compute an expected execution profile per request: {uncached_tokens, full_context, kv_hit_ratio} -> choose kernel heuristics that prefer "short-seq fast-path" when uncached small AND kernel transform scales with full_context.
