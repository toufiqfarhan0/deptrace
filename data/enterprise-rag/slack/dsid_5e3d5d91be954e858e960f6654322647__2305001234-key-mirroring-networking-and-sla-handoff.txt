Sam Green: Thanks Jess. Short answers: we support BYO-HSM via our key proxy. Mirroring adds round-trip for key unwraps if you route to remote HSM. Usually add 5-25ms per call depending on region pair. For cross-region active-active you'd want local routing + async replication to avoid per-request cross-region calls.

Matt O'Leary: Exactly — recommend local primary + async mirror. If they insist on synchronous mirroring, they pay the latency. For POC we can show both modes.

Alex Rivera: Network: outbound TLS to customer HSM endpoints. Ports: TCP 443 for HTTPS, TCP 1050-1060 if they use PKCS#11 over TCP (some vendors). We need static IPs for allow-listing; we'll provide the egress IPs from the Dedicated pool. Also need MTU/keepalive tuned for long-lived tunnels.

Lisa Park: Compliance note: mutual-TLS + client certs required for HSM connections. Customer-managed keys (BYOK) must have rotation policy documented; for some regulated customers we require rotation window >= 30 days and audit logs forwarded. Key escrow: we do not escrow customer CMKs unless explicitly contracted.
