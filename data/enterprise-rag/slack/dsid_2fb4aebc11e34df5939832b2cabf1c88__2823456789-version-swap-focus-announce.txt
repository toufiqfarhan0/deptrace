diego: Pseudocode for the anchor flow:
```
const anchor = document.createElement('span');
anchor.tabIndex = -1; anchor.id = `focus-anchor-${rowId}`;
row.after(anchor);
anchor.focus({preventScroll:true});
// perform version swap update
// after render or on next animation frame:
const newLabel = document.getElementById(`version-label-${rowId}`);
if (newLabel) newLabel.focus({preventScroll:true});
anchor.remove();
```
