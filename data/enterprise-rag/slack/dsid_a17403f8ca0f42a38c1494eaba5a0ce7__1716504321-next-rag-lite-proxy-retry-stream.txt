    method: req.method,
    headers: { 'content-type': 'application/json' },

paul: That drops auth. Also using req.url when behind Next rewrites can be brittle. Suggest forwarding incoming auth headers and fallback to REDWOOD_SERVER_TOKEN env if present. Example:
```
const headers = {
  'content-type': 'application/json',
  ...(req.headers.authorization ? { authorization: req.headers.authorization } : {}),
  ...(req.headers.cookie ? { cookie: req.headers.cookie } : {}),
  ...(process.env.REDWOOD_SERVER_TOKEN ? { authorization: `Bearer ${process.env.REDWOOD_SERVER_TOKEN}` } : {}),
}
```
