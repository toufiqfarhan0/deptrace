maria: here's a rough internal API idea and the response header handshake we discussed:

```
# routing policy fragment
{
  "policy_id": "cheap_handshake_v1",
  "target_tiers": ["starter","growth"],
  "region_constraints": ["eu-*","ap-*"],
  "cheaper_variants": [
    {"model": "open-llama-13b-q4", "max_quality_drop": 0.06, "weight": 0.7},
    {"model": "meta-mpt-7b-q4", "max_quality_drop": 0.12, "weight": 0.3}
  ],
  "token_savings_threshold": 0.15
}
```

And runtime might return a hint header when a cheaper candidate exists: `x-rwd-route-hint: cheap_handshake_v1;candidate=open-llama-13b-q4;cost_delta=0.27`
