```bash
# alias: map a shorthand to a multi-step rollout
/release-bot alias add canary_safe --steps \"canary,slow_gradual,full\" --wait 10m

/release-bot rollback start --mode stepwise --checks \"smoke,perf,logs\"
# generate compact annotated notes and attach a snapshot id
/release-bot notes gen --template compact --attach-snapshot
```

Morgan: Sketch of a minimal stepwise-rollback playbook we can wire into the bot: 
```
1) stop new traffic routing (cmd)
2) snapshot current deployment: `/release snapshot create --id $TS`
3) rollback step 1 -> previous canary
4) monitor 10m for errors / perf regressions
5) if metrics green, rollback step 2 -> full revert to previous stable
6) if not, abort and escalate to SRE + oncall
```
