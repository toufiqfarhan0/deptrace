rahul: Implementation proposal: two-tier telemetry approach — (1) sampled per-invocation enrichment (1%) that includes cache_credit enum, latency, tokens; (2) aggregate counters for the whole stream (per-minute/per-route) for live dashboards. For accurate previews, run an on-demand replay job over last N hours of traces.

kevin: Example query to compute baseline numbers (quick prototype):
```sql
SELECT model_id, route_id, SUM(tokens) AS tokens, SUM(cache_hits) AS hits, SUM(tokens) - SUM(cache_hits)*avg_saved_tokens AS net_tokens
FROM invocation_aggregates
WHERE ts >= now() - interval '6 hours'
GROUP BY model_id, route_id;
```
This uses aggregate rows so we avoid exploding cardinality.
