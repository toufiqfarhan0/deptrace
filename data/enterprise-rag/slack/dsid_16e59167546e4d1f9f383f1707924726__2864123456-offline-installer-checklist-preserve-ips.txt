jana.pm: Checklist sketch included below: 
```
- Preflight: kernel modules, required sysctl, free disk, cert chain hash match
- Network contract: `--preserve-ips` opt-in (enterprise default), documented port map, explicit external IP mapping policy
- Image/manifest: signed manifest + sha256, offline verifier tool, manifest timestamp & vendor cert
- Upgrade lanes: patch=rolling drain -> image swap; minor=rolling + cache migration shim; major=canary subnet -> 24h gather -> staged cutover
- Readiness: runtime readiness probe + KV cache warm endpoint, configurable drain-timeout per tenant
- Rollback: automatic image fallback, route table restore script, manifest revert checklist
- Offline keys: escrow instructions, step-by-step key rotation without CA access
- Telemetry: limited heartbeat pings optional; signed install logs for support bundle
```
